OpenWeedLocator on Jetson Nano: Embedded Real-Time Weed Detection

Ported OpenWeedLocator (OWL) computer vision weed detection pipeline to the NVIDIA Jetson Nano 2GB with high-throughput MIPI-CSI camera streaming via GStreamer nvarguscamerasrc and low-latency GPIO actuator triggering.

Firmware / ROS 2 Repo↗

1. Project Overview

OpenWeedLocator (OWL) is an open-source precision agriculture weed detection platform originally developed for Raspberry Pi single-board computers to enable low-cost, site-specific herbicide spot spraying.

This project ported the complete OWL computer vision and real-time actuation architecture to the NVIDIA Jetson Nano 2GB Developer Kit. The system interfaces a compatible camera module over the native MIPI-CSI-2 camera port, leveraging hardware-accelerated video capture to reliably detect green foliage and trigger targeted spray relays with minimal latency.

Source code and setup scripts: sriharshakunda/OWL-Jetson (jetson_nano2gb branch).

2. Key Technical Implementations

Hardware-Accelerated MIPI-CSI Camera Pipeline

The standard Raspberry Pi camera interface was replaced with a custom threaded GStreamer capture backend leveraging NVIDIA JetPack’s nvarguscamerasrc and nvvidconv hardware plugins:

gst_pipeline = (
    "nvarguscamerasrc ! "
    "video/x-raw(memory:NVMM), width=1280, height=720, framerate=30/1 ! "
    "nvvidconv ! "
    "video/x-raw, format=BGRx ! "
    "videoconvert ! "
    "video/x-raw, format=BGR ! appsink"
)
  • Zero-Copy Frame Processing: Bypasses CPU-bound V4L2 software decoding by offloading frame acquisition and format conversion directly to Jetson’s hardware ISP.
  • Threaded Frame Reader: A dedicated GStreamerStream thread with event locks continuously grabs frames, preventing I/O blocking from stalling the detection loop.

Jetson.GPIO Actuator & Relay Triggering

  • Re-architected output management from Raspberry Pi RPi.GPIO to Jetson.GPIO, dynamically identifying the hardware platform via /proc/device-tree/model.
  • Drives multi-channel relay modules connected to the 40-pin header to energize 12V spot-spray solenoids within milliseconds of weed classification.

Optimized Jetson Setup Script

  • Created an automated setup routine (owl_setup.sh) tailored for JetPack on 2GB Nano boards, removing unnecessary desktop packages (Wolfram, LibreOffice) to maximize available RAM, configuring Python virtual environments, and compiling OpenCV with GStreamer support.

3. Results & Demonstration

The embedded pipeline runs real-time green-on-brown weed detection at 30 FPS over the MIPI-CSI bus, accurately segmenting vegetation and actuating output relays with minimal end-to-end latency suitable for tractor- and robot-mounted spot spraying.
